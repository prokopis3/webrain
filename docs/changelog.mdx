# Changelog

All notable changes, in reverse chronological order. The full version lives in
[`CHANGELOG.md`](https://github.com/prokopis3/webrain/blob/main/CHANGELOG.md).

## v0.3.1 - 2026-08-05

### Added

- **cli**: `webrain install --engine lightpanda` now downloads the lightpanda binary from the `lightpanda-io/browser` GitHub release into the engine cache, mirroring `--engine obscura`; `find_lightpanda()` also discovers the cached build. No Windows binary - the install bails with the Docker fallback instead of silently installing Chrome.

### Changed

- **cli**: `webrain install --engine <unknown>` now errors clearly instead of silently installing Chrome.

### Fixed

- **mcp**: `webrain_open_session(cdp_url=…)` now actually routes tools to that session (every browser tool accepts an optional `session_id`).
- **mcp**: a browser kill/restart no longer wedges the cached backend forever - dead-socket errors drop the backend so the next call reconnects.
- **core**: the CDP WebSocket connect retries once with a longer budget (20s), tolerating obscura's slow cold-start handshake.

---

## v0.3.0 - 2026-08-05

### Added

- **tools**: `webrain_page_info` - just-in-time page context (viewport/page size, scroll position, position %).
- **tools**: `webrain_save_state` / `webrain_restore_state` - export/import auth state (cookies + localStorage) across machines.
- **cli**: `webrain -v` / `--version` / `version`.

### Fixed

- **core**: `webrain install` failed with "response body is larger than request limit" - ureq's 10 MB cap was too small for the Chrome/Obscura engine zips; now reads via the unlimited reader.

### Changed

- **docs**: rewrote README (install-first, "Why webrain?", use-cases, Scoop extras).
- **build**: moved `Dockerfile` into `docker/` + added `docker-compose.yml` (persistent vault/profile/cache volumes).
- **tools**: deduped the JS→JSON parse chain in `tools.rs` into `parse_json_str` / `arr_len`.

---

## v0.2.0 - 2026-08-05

### Added

- **cli**: `webrain upgrade` - updates to the latest release (Homebrew/Scoop-aware, else self-updates in place).
- **install**: one-line installers - `scripts/install.sh` (Linux/macOS) and `scripts/install.ps1` (Windows).
- **dist**: submitted to the official Scoop `extras` bucket and published a Homebrew tap (`prokopis3/homebrew-webrain`).
- **docs**: `CONTRIBUTING.md`, README badges, Quick Start + Traditional Selectors + Commands + Updating.

## v0.1.1 - 2026-08-04

### Added

- **docs**: all-OS install one-liners (PowerShell + curl) and the working scoop bucket (`prokopis3/scoop-webrain`).

### Fixed

- **ci**: the Linux release binary now builds on `ubuntu-22.04` (glibc 2.35) - the previous `ubuntu-latest` build required glibc 2.39.

## v0.1.0 - 2026-08-04

### Added

- **workspace**: Cargo workspace (`resolver 3`, `edition 2024`, Rust 1.85) with `webrain-core` / `webrain-mcp` / `webrain-cli`; MIT license; CI + release + changelog-enforce workflows.
- **core**: Rust CDP browser-automation agent - one `BrowserBackend` trait over CDP WebSocket (`CdpBackend`) driving Chrome, Edge, Lightpanda, or Obscura; `SessionPool` isolation; `STEALTH_JS` anti-bot injection.
- **mcp**: stdio JSON-RPC server owning the CDP connection, 25-tool dispatch table.
- **cli**: single `webrain` binary, `match`-based subcommands (no clap) mirroring the MCP tool surface.
- **core**: page interaction (navigate/eval/click/type/press/scroll/snapshot, multi-tab, a11y), capture (screenshot, PDF, PixelRAG vision tiles + cosine `VectorStore`), extraction (`extract_json` / `extract_regex` / `eval`), spider + web search, batch + download.
- **cli**: `webrain doctor` - full install diagnosis (exit 0 when a browser is reachable).
- **core/cli**: agent-browser-style engine install - `webrain install` downloads Chrome for Testing (and `--engine obscura`); `webrain lightpanda` / `webrain obscura` spawn CDP servers.
