# Structured Extraction

Webrain turns an unknown page into structured JSON without you writing a single
selector. The zero-LLM discovery pipeline is:

## 1. Discover the container

```text
webrain_extract(mode=autoschema)   → candidate base-selectors + occurrence counts
```

`webrain_extract` (mode: `autoschema`) detects repeated container patterns on
the page and returns candidate base-selectors — e.g. `.product`, `li.item`.
Zero LLM.

## 2. Probe the structure

```text
webrain_eval   → probe descendant tags/classes + samples → pick fields
```

Run small JavaScript to inspect what lives inside a container before you
declare fields.

## 3. Extract

`webrain_extract` (mode: `schema`) builds a JSON array from a base selector +
field selectors:

```json
{
  "base_selector": ".product",
  "fields": [
    { "name": "title", "selector": "h3 a", "type": "text" },
    { "name": "price", "selector": ".price", "type": "text" },
    { "name": "href", "selector": "a", "type": "attr", "attr": "href" }
  ]
}
```

Set `adaptive: true` to auto-relocate the container when the base selector
matches nothing (site redesigned) — it finds elements still containing ≥2 of
the field selectors.

## Other extractors

| Tool | Use for |
|---|---|
| `webrain_extract` (mode: `regex`) | emails, phones, prices, dates, IPs + custom patterns |
| `webrain_extract` (mode: `table`) | every HTML `<table>` on the page → JSON rows |
| `webrain_extract` (mode: `jsonld`) | schema.org JSON-LD / microdata — free, zero cost |
| `webrain_extract` (mode: `bm25`) | BM25 relevance filter — keep only the top-k relevant items |
| `webrain_observe` (what: `clean`) | strip nav/footer/social noise → clean text blob |

## Token discipline

<Warning>
  **Never reach for `webrain_observe` (what: `html`) for page text.**
  `webrain_observe` (what: `state` / `clean`), `webrain_eval`, and the
  extractors return text/structure far cheaper. `html` is the **LAST resort** —
  only when the task explicitly asks for raw markup.
</Warning>

## The full recipe for paginated catalogs

```text
1. webrain_navigate(seed)         → read `links` + `challenge`
2. webrain_eval                   → discover pagination hrefs structurally
                                   (same-prefix numeric links + next/prev)
3. derive urls (page range)
4. webrain_extract(mode=autoschema) → container selector
5. webrain_eval                   → descendant tags/classes + samples → fields
6. webrain_batch(op=extract, urls, base_selector, fields, concurrency=8)
```

Proven flow — no class assumptions, no `get_html`.
