# Installation

Pick a path. All of them give you the `webrain` binary; the first run of
`webrain install` downloads the browser engine.

## Global installation (recommended)

<CodeGroup>

```bash Linux / macOS
curl -fsSL https://raw.githubusercontent.com/prokopis3/webrain/main/scripts/install.sh | bash
```

```powershell Windows
irm https://raw.githubusercontent.com/prokopis3/webrain/main/scripts/install.ps1 | iex
```

</CodeGroup>

Then, in any terminal:

```bash
webrain install          # Download Chrome for Testing (first time only)
webrain mcp --http 9223  # start the MCP server
```

### Manual download

<CodeGroup>

```powershell Windows
$dir = "$env:LOCALAPPDATA\Programs\webrain"
New-Item -ItemType Directory -Force -Path $dir | Out-Null
Invoke-WebRequest "https://github.com/prokopis3/webrain/releases/latest/download/webrain-windows.exe" -OutFile "$dir\webrain.exe"
[Environment]::SetEnvironmentVariable("Path", "$([Environment]::GetEnvironmentVariable('Path','User'));$dir", "User")
# open a new terminal, then:
webrain install
webrain mcp --http 9223
```

```bash Linux / macOS
curl -L -o ~/.local/bin/webrain https://github.com/prokopis3/webrain/releases/latest/download/webrain-linux
chmod +x ~/.local/bin/webrain
webrain install
webrain mcp --http 9223
```

</CodeGroup>

<Note>
  macOS: swap `webrain-linux` for `webrain-macos` in the curl line.
</Note>

## Package managers

<CodeGroup>

```bash Homebrew (macOS)
brew tap prokopis3/webrain
brew install webrain
webrain install
```

```powershell Scoop (Windows)
scoop bucket add webrain https://github.com/prokopis3/scoop-webrain
scoop install webrain
webrain install
```

```bash Cargo (Rust)
cargo install --git https://github.com/prokopis3/webrain webrain-cli
webrain install
```

</CodeGroup>

## From source

```bash
git clone https://github.com/prokopis3/webrain
cd webrain
cargo build --release --bin webrain
./target/release/webrain install   # Download Chrome (first time only)
./target/release/webrain mcp --http 9223
```

## Linux dependencies

Chrome needs system libraries on Linux. Install them before first run:

<CodeGroup>

```bash Debian / Ubuntu
sudo apt-get install -y libnss3 libnspr4 libxkbcommon0 libatk1.0-0 \
  libatk-bridge2.0-0 libxcomposite1 libxdamage1 libxrandr2 libxfixes3 \
  libxcursor1 libxi6 libxtst6 libxss1 libxext6 fonts-liberation
```

```bash Fedora
sudo dnf install -y nss nspr libxkbcommon atk at-spi2-atk at-spi2-core \
  libXcomposite libXdamage libXrandr libXfixes libXcursor libXi libXtst \
  libXScrnSaver libXext
```

</CodeGroup>

If you see *"shared library"* errors when running Chrome, that's the
missing-deps symptom — install the list above.

## Updating

```bash
webrain upgrade
```

Detects your install method (Homebrew, Scoop, or manual) and updates
automatically. For a cargo install:

```bash
cargo install --git https://github.com/prokopis3/webrain webrain-cli --force
```

Re-download engines after an update (the cache dir stays; versions are
additive):

```bash
webrain install
webrain install --engine obscura
```

## OS compatibility

| Engine | Windows | macOS | Linux |
|---|---|---|---|
| Chrome for Testing (`webrain install`) | ✅ | ✅ | ✅ |
| Obscura (`webrain install --engine obscura`) | ✅ x86_64 | ✅ x86_64 / arm64 | ✅ x86_64 / arm64 |
| Lightpanda (`webrain lightpanda`, binary needed) | ⚠️ (needs a Windows build on PATH) | ✅ | ✅ |
| Docker (`docker/Dockerfile`) | via Docker Desktop | via Docker Desktop | ✅ |

Binary discovery is automatic on every OS: env override → PATH → `~/.lightpanda`,
`~/.obscura`, `~/.local/bin` → the webrain engine cache.

### Optional bundles

`webrain install` also supports two self-contained mono bundles (no PATH
installs, any OS):

```bash
webrain install watch    # ffmpeg+ffprobe, yt-dlp, whisper-cli + GGUF model — powers webrain_watch
webrain install vision   # llama-server + the default local vision model — powers watch --vision + webrain_vision
```

`install vision` takes exactly one model id (`--model <id>` or the bare
positional `install vision <id>`); anything else prints the choices with
download size and RAM/VRAM instead of fetching a repo:

```bash
webrain install vision --model qwen3-vl-2b-q6k   # recommended 2B (1.4 GB + 819 MB)
webrain install vision --model qwen35-9b-q4km    # 9B distill   (5.6 GB + 922 MB)
webrain install vision --model qwen3-vl-2b --model-update  # re-check files on Hugging Face
webrain uninstall vision --model qwen35-9b-q4km  # free the disk space
webrain uninstall vision --all                   # remove every local vision model
```

| id | model | download | needs |
|---|---|---|---|
| `qwen3-vl-2b` | Qwen3-VL-2B-Instruct Q4_K_M | 1.1 GB + 819 MB | 8–16 GB RAM, 2–4 GB VRAM |
| `qwen3-vl-2b-q6k` | Qwen3-VL-2B-Instruct Q6_K *(recommended)* | 1.4 GB + 819 MB | 8–16 GB RAM, 2–4 GB VRAM |
| `qwen35-9b-q4km` | Qwen3.5-9B-DeepSeek-V4-Flash Q4_K_M | 5.63 GB + 922 MB | 16–32 GB RAM, 8–12 GB VRAM |
| `qwen35-9b-q5km` | Qwen3.5-9B-DeepSeek-V4-Flash Q5_K_M | 6.47 GB + 922 MB | 16–32 GB RAM, 10–12 GB VRAM |
| `qwen35-9b-q6k` | Qwen3.5-9B-DeepSeek-V4-Flash Q6_K | 7.36 GB + 922 MB | 24–32 GB RAM, 12–16 GB VRAM |
| `qwen35-9b-q8` | Qwen3.5-9B-DeepSeek-V4-Flash Q8_0 | 9.53 GB + 922 MB | 32–64 GB RAM, 16 GB+ VRAM |

Each entry brings its own mmproj (`mmproj-F16.gguf` for the 2B, `mmproj.gguf`
for the 9B); models land in `vision/<id>/` and an existing single-model install
keeps working. Download sizes are the exact blob sizes on Hugging Face; the
RAM/VRAM columns are guidance, not a measured fit — a 9B at Q4_K_M is 5.63 GB of
weights plus 922 MB of projector before any KV cache. The 9B quants need a
GPU-enabled `llama-server` (`WEBRAIN_LLAMA_SERVER`) to be worth it — the bundled
build is CPU-only.
